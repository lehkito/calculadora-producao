# Calculadora de produção

Calculadora no navegador para impressão, corte, liner e cola. Bolsa disponível como acessório opcional, desativado por padrão.

Abra index.html no navegador ou acesse o site publicado pelo GitHub Pages. Não há histórico nem armazenamento dos orçamentos.

Preços fixos na constante FIXED em index.html. Impressão com perda de 11%; demais etapas com 8%. O custo da bolsa não entra no total: somente seu consumo é calculado.

O botão de download gera uma cópia HTML para uso offline no computador.
